# BreadCrumber

App per macOS che registra le call di Google Meet, le trascrive e scrive il recap.

**[Scarica l'ultima versione](https://github.com/abiagioDev/breadcrumber/releases/latest)**: apri il DMG e trascina BreadCrumber in Applicazioni. Gli aggiornamenti arrivano da soli.

Richiede macOS 26 o successivo.
